# PM / TPM Prompt Library

## Daily brief
Using only supplied authorized evidence, summarize changes, decisions, overdue actions, changed risks/dependencies and conflicts. Do not infer owners/dates/commitments.

## Meeting
Extract explicit decisions/actions. Owner/due only when stated; otherwise Missing. Separate proposals.

## Requirements
Extract stated requirements, then assumptions/open questions; propose acceptance criteria separately.

## Status
Draft from baseline/forecast/RAID/budget/quality. Do not invent RAG, ETA, percentages, financials or root cause.

## Incident
Separate facts, missing evidence and hypotheses. Suggest safe diagnostics; do not state unsupported root cause.
