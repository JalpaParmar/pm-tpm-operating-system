# Budget & Metrics Review Checklist

- [ ] approved baseline/source/date known
- [ ] actuals refreshed from finance source
- [ ] remaining forecast updated
- [ ] EAC and variance calculated consistently
- [ ] major variance causes explained
- [ ] scope/schedule/risk connection understood
- [ ] outcome/value status visible
- [ ] metric definitions documented
- [ ] trends used rather than isolated points
- [ ] quality/release signals included
- [ ] metrics not used as individual performance scores
- [ ] decisions/actions explicit
