# Project Initiation Checklist

- [ ] sponsor/accountable owner identified
- [ ] problem/opportunity stated
- [ ] objectives/outcomes agreed
- [ ] success measures defined or explicitly pending
- [ ] scope in/out documented
- [ ] major deliverables/milestones understood
- [ ] stakeholder register created
- [ ] ambiguous ownership resolved
- [ ] assumptions/constraints visible
- [ ] initial risks/dependencies assigned
- [ ] governance/escalation cadence agreed
- [ ] kickoff decisions/actions captured
- [ ] approval status documented
- [ ] detailed planning can begin
