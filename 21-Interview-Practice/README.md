# PM / TPM Interview Practice

Use the operating system to explain **how you think and operate**, then answer with real experience.

## Scenario bank
1. API dependency will miss the mobile integration date.
2. Scope increases after baseline approval.
3. Forecast EAC exceeds budget.
4. Predictability falls while scope churn rises.
5. Steering committee needs a decision today.
6. Release has one unresolved critical compatibility defect.
7. Production errors rise after phased rollout.
8. Executive asks for root cause before evidence exists.
9. Team wants to automate project status using AI.
10. Project delivered but support/handover is incomplete.

## Answer framework
Context → impact/risk → evidence → options → decision/action → communication → validation/result.

## Rule
Never present the repository's fictional worked project as personal experience.
