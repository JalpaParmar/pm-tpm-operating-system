# Worked Example — Project Initiation

**Illustrative fictional project:** Customer Appointment Reminder Modernization.

Problem: reminder delivery is fragmented across legacy workflows, making status visibility/failure handling inconsistent.

Objective: consolidate reminder workflow with clear delivery status and operational monitoring.

In scope: orchestration, API integration, mobile/web status visibility, monitoring and rollout.

Out of scope: replacing external SMS/email providers.

Stakeholders: Sponsor, Product, PM/TPM, Backend, Mobile, QA, Operations.

Dependencies: provider limits, backend event contract, mobile API availability, operational dashboard.

Risks: backward compatibility, duplicate reminder delivery during migration, provider rate limits.

This is fictional and not employer/customer data.
