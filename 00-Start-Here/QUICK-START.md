# Quick Start

**Starting a project:** Initiation → Planning → Resources → RAID/Dependencies → Governance.

**Running delivery:** Agile Execution → RAID/Change → Budget/Metrics → Weekly Status.

**Off track:** Iteration Off-Track / Dependency Delay / Forecast Variance / Project Recovery playbooks.

**Executive meeting:** Executive Summary → Steering Committee → decision/escalation.

**Releasing:** Release → Quality → TPM Technical Governance → readiness evidence.

**Production issue:** Incident/RCA → timeline → mitigation → recovery validation → actions.

**AI help:** use AI-Assisted PM but validate evidence, numbers, owners, dates and consequential decisions.

**Interview:** scenario bank + real STAR stories; do not memorize every template.
