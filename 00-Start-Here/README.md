# Start Here

## What this repository is
A working PM/TPM toolkit combining **artifacts + operating guidance + examples + interview practice**.

## How to use it
### Starting a project
Initiation → Planning → Resources → RAID/Dependencies → Communication/Governance.

### Running delivery
Agile/Execution → RAID → Metrics → Stakeholder Status → Change → Quality.

### Preparing release
Release → Quality → Technical Governance → Production Readiness → Communication.

### Handling trouble
Issue/Risk → relevant Playbook → escalation/decision → Incident/RCA if production impact exists.

### Interview preparation
Use worked examples and scenario playbooks to understand the process, then answer from your **real experience**.

## Artifact maturity
- **Reference:** explanatory Markdown.
- **Template:** reusable blank structure with instructions.
- **Example:** fictional worked artifact.
- **Operational:** ready-to-use file with formulas/validation where applicable.

## Important
Do not fill every template for every project. Tailor governance to project size, risk and organizational requirements.
