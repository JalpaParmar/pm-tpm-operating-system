# Artifact Map

## Initiation
Project Charter, Stakeholder Register, RACI, Kickoff.

## Planning
WBS, Milestone Plan, Schedule, Estimation, Resource/Capacity Plan.

## Control
RAID Register, Dependency Tracker, Decision Log, Change Log/Request.

## Financial
Budget Tracker, Forecast, Variance, Cost-to-Value view.

## Delivery health
Sprint/Flow Dashboard, Predictability, Scope Churn, Quality, DORA-aware delivery signals.

## Communication
Weekly Status, Executive Summary, Steering Deck, Communication Plan.

## Release
Release Plan, Readiness Checklist, Go/No-Go, Rollback/Mitigation.

## Incident
Incident Timeline, Stakeholder Update, RCA, Corrective Actions.

## Closure
Handover, Lessons Learned, Closure Report.

Later phases will add the actual reusable files and worked examples.
