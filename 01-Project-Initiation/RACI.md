# RACI

R — Responsible; A — Accountable; C — Consulted; I — Informed.

## Rules
- Prefer one clear A per activity/decision where practical.
- At least one R for executable work.
- Do not create a giant RACI for every task.
- Use it where cross-functional ownership/decision rights are ambiguous.

| Activity | Sponsor | Product | PM | TPM | Eng Lead | QA | Ops |
|---|---|---|---|---|---|---|---|
| Approve charter | A | C | R | C | C | I | I |
| Product scope | C | A | R | C | C | C | I |
| Architecture decision | I | C | C | R | A | C | C |
| Release go/no-go | A | C | R | R | C | C | C |

Illustrative only; adapt to organizational decision rights.
