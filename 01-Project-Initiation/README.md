# Project Initiation

Phase 2 establishes enough clarity and ownership to authorize detailed planning.

## Flow
Problem/opportunity → objectives → scope → stakeholders → ownership → assumptions/constraints → initial risks/dependencies → governance → kickoff → approval.

Do not call initiation complete merely because kickoff occurred. Outcome/scope, decision ownership, major stakeholders, material assumptions/constraints and the planning path should be clear enough to proceed.
