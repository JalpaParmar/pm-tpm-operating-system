# Budget & Financials

Phase 6 operating guidance for approved budget, actuals, remaining forecast, Estimate at Completion (EAC), variance, burn and cost-to-value discussion.

## Core formulas
**EAC = actual to date + remaining forecast** in the provided template. **Forecast variance = approved budget - EAC.** State sign conventions clearly because organizations differ.

Budget management is not only cost control: connect spend to outcomes, scope, schedule and risk.
