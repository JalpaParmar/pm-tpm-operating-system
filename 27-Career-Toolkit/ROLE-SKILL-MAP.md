# Role Skill Map

| Role | Must Know | Strong Differentiators |
|---|---|---|
| PM | planning, RAID, stakeholders, change, budget, quality | forecasting, governance, recovery |
| TPM | PM + APIs/architecture/release/observability | technical dependency leadership, incidents |
| Technical Program Manager | program dependencies, governance, executive decisions | architecture boundaries, systemic metrics |
| Engineering Manager | people + delivery + technical judgment | engineering health, mentoring, incidents |
| AI PM | PM + AI workflow/evaluation/risk | data/context, agents/tools, governance |
