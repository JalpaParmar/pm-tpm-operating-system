# PM / TPM Operating System

A practical, reusable operating system for **Project Managers, Technical Project Managers and delivery leaders**.

This repository is designed to help someone **run a project**, not merely read PM theory.

> **Understand → Plan → Execute → Measure → Communicate → Improve**

## Artifact philosophy
This repo will include more than Markdown. Later phases will add reusable **Excel workbooks, Word documents and PowerPoint decks** where those formats are genuinely useful.

Every artifact should include:
1. purpose;
2. when to use it;
3. owner/update cadence;
4. instructions;
5. worked example or sample data where appropriate;
6. quality checks.
