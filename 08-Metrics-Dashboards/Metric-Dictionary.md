# Metric Dictionary

| Metric | Definition | Caution |
|---|---|---|
| Predictability | completed original commitment / original commitment | show scope changes too |
| Scope churn | (added + removed) / original commitment | churn can be legitimate |
| Cycle time | elapsed time from defined work-start to done | define start/end consistently |
| Flow efficiency | active work / elapsed flow time | needs reliable active-time data |
| EAC | expected total cost at completion | forecasting method may vary |
| Budget variance | approved budget - EAC in this OS | state sign convention |
| Change failure | release/change needing remediation | use one organizational definition |
| Recovery time | time to restore service | define incident start/recovery |

DORA-related measures should use current, consistent organizational definitions rather than being mixed casually with team velocity.
